# SS Guardia — descargas

Instalador de **SS Guardia** para Windows 10/11 (SimpleSolutions).

Descargá el archivo terminado en `-setup.exe` del [último release](../../releases/latest).
La app se actualiza sola: cuando hay una versión nueva, avisa y se instala con un clic.

Este repositorio sólo contiene los instaladores firmados. No contiene código.
